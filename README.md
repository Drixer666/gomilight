# GOMI LIGHT · Gomitas saludables de Pachacutec

Web oficial del emprendimiento escolar de la I.E. N° 5130 Pachacutec (Ventanilla, Callao).

Gomitas con fruta real, pectina natural y 0% azúcar añadida.

## Páginas
- `#/` Inicio
- `#/sabores` Los 4 sabores
- `#/nutricion` Tabla nutricional y comparativa
- `#/historia` El proyecto y el proceso
- `#/tienda` Packs y pedido por WhatsApp
- `#/faq` Preguntas frecuentes
- `#/contacto` Formulario y taller

## Publicación
Este repositorio usa **GitHub Pages**: Settings → Pages → Branch `main` → Save.

## Actualizar la web
Reemplaza `index.html` por la nueva versión y haz commit. La web se actualiza sola en 1-2 minutos.
